# RS & STEM Education Website

Starter GitHub Pages website.

## Publish
1. Create a public GitHub repository.
2. Upload all files and folders from this package.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. Wait a few minutes for GitHub Pages to publish.

## Replace the banner
Replace `images/banner.jpg` with a wide agricultural, UAV, or satellite image using the same filename.

## Edit content
Open any `.html` file in GitHub and click the pencil icon.
